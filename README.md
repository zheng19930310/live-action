# live-action · 3D 实景展示

基于 three.js + GaussianSplats3D 的 3D 高斯泼溅（3DGS）实景模型网页展示器。

## 使用

```powershell
cd d:\llmwork\live-action
python -m http.server 8090
# 浏览器打开 http://localhost:8090
```

- `res/` 存放建模文件（.ply 为主，也兼容 .splat / .ksplat / .spz）。
- 放入新模型后，在 `res/manifest.js` 的 `SPLAT_MANIFEST` 数组登记一行即可在右下角切换。
- 支持直接把本地建模文件拖进网页预览；也支持 `?file=res/xxx.ply&name=名称` 临时指定。
- CDN 依赖 jsDelivr（three@0.160 + @mkkellogg/gaussian-splats-3d@0.2.3），需联网。

## 版本

- `v1.0.html` —— 上一版快照（双击中心点 + 方向盘 + 平移/旋转切换 + 2D 箭头），独立可直接打开。
- `index.html` —— 当前版，在 v1.0 上增加：右上角 XYZ 坐标与方位罗盘、无限制的旋转幅度、3D 旋转箭头。

## 操作

- 鼠标：左键拖拽旋转 · 滚轮缩放 · 右键平移
- **双击**画面任意模型处，将该点设为旋转中心（单击不会误改中心）
- 左下角 3×3 方向盘：上、下、左、右 + 四个倾斜方向，按住可持续绕中心点转动
- 方向盘右侧切换 **旋转 / 平移**：旋转=相机绕中心环绕；平移=相机与中心一起位移
- 操作时中心点处会画出方向箭头：**旋转为环绕中心点的 3D 圆环**（画在真实转动平面里，随视角产生透视：俯视接近正圆、平视被压扁），平移为沿相机轴的 3D 直线箭头；箭头方向与相机实际运动方向一致
- 旋转幅度不再受限：上/下可连续翻转整圈（越过顶部/底部不会卡住），左/右可无限转圈；实现上是四元数同时转动“相机偏移 + 相机 up”，避开球坐标 phi 在极点的奇点，代价是越过顶部后画面会随刚体滚动
- 右上角实时显示 **XYZ 坐标**（相机位置 / 中心点位置 / 方位角・仰角・距离）与一个 **XYZ 三轴罗盘**，随时知道方向；可用右下角“坐标 开/关”关闭
- “回到初始中心”同时复位相机（位置 (0, 1.5, 6)、up (0, 1, 0)、中心 (0, 0, 0)）
- 右下角按钮切换 `res/manifest.js` 中的模型，并可开关地面网格
